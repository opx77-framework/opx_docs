title: Server

Every export is synchronous, except `GetCharacters`, `CreateCharacter`, `DeleteCharacter` and `LoadCharacter`, which wait for the account when it is not cached yet (check `IsAccountReady`, or call them after `opx:playerLoaded`). A player is loaded between `opx:playerLoaded` and `opx:playerUnloaded`; outside that window source-based exports answer `'not_loaded'`.

## GetPlayer

PlayerData of a loaded character.

```lua
exports.opx_core:GetPlayer(source)
```

- source: `number`

**Returns**

- data?: `table`
  - source: `number`
  - identifier: `string` (`"license:<hex>"`)
  - citizenId: `string` (`"AB123456"`)
  - firstname, lastname: `string`
  - birthdate: `string` (`'YYYY-MM-DD'`)
  - family: `'male'` or `'female'`
  - accounts: `table<string, number>` (`{ money = 500, bank = 5000 }`)
  - job: `table` (see [SetJob](#setjob))
  - metadata: `table<string, any>` (includes `health`, fraction 0..1)
  - position?: `{ x, y, z, heading }`
  - isNew: `boolean` (true until `SetCharacterCreated`)

## RegisterJob

Registers a job owned by the calling resource. Its jobs are dropped when it stops: register from `onResourceStart` for your own start and for `opx_core`'s.

```lua
exports.opx_core:RegisterJob(name, definition)
```

- name: `string`
  - `^[a-z][a-z0-9_]{1,31}$`
- definition: `table`
  - label: `string` (up to 64 characters)
  - grades: `table<number, { name: string, label: string, salary: number }>`
    - Keys contiguous from `0`, 1 to 50 grades.
  - defaultDuty?: `boolean` (duty when the job is given, default `false`)
  - offDutyPay?: `boolean` (paid off duty, default `false`)
  - type?: `string` (`'leo'`, `'ems'`, `'mechanic'`...)
  - data?: `table` (JSON-able, up to 8 KiB)

**Returns**

- ok: `boolean`
- reason?: `'invalid_name'`, `'invalid_definition'`, `'invalid_label'`, `'invalid_grades'`, `'invalid_type'`, `'invalid_data'`, `'job_taken'`

```lua
exports.opx_core:RegisterJob('police', {
  label = 'NCPD',
  type = 'leo',
  grades = {
    [0] = { name = 'cadet', label = 'Cadet', salary = 150 },
    [1] = { name = 'officer', label = 'Officer', salary = 250 },
  },
})
```

## Notify

Notification through the notify provider (the game's own toast when none runs).

```lua
exports.opx_core:Notify(source, message, type, duration, title, options)
```

- source: `number` (`-1` = everyone)
- message: `string`
- type?: `'info'`, `'success'`, `'warning'`, `'error'`
- duration?: `number`
  - Milliseconds, 500 to 60000. `nil` = provider default.
- title?: `string`
- options?: `table`
  - id?: `string` or `number` (a line with the same id is updated in place)
  - persist?: `boolean` (stays until dismissed)

**Returns**

- ok: `boolean`
- reason?: `'invalid_source'`, `'invalid_message'`

## NotifyLocale

Notification written in the caller's `locales/<lang>.json`, translated by the caller's client. That client must `require('@opx_core')`.

```lua
exports.opx_core:NotifyLocale(source, key, params, type, duration, titleKey, options)
```

- source: `number` (`-1` = everyone)
- key: `string`
  - 1 to 64 bytes of letters, digits, `_ . : -`
- params?: `table<string, string | number>`
  - Values for `{name}` placeholders, up to 16 entries.
- type?, duration?, options?: as `Notify`
- titleKey?: `string`

**Returns**

- ok: `boolean`
- reason?: `'invalid_source'`, `'invalid_key'`, `'invalid_params'`

```lua
exports.opx_core:NotifyLocale(source, 'paid', { amount = 50 }, 'success')
```

## RegisterCallback

A server callback answered by the calling resource's export `exportName(source, ...)`. Clients ask it with `OPX.TriggerServerCallback` / `OPX.AwaitCallback`. Register from `onResourceStart` and again when `opx_core` restarts.

```lua
exports.opx_core:RegisterCallback(name, exportName)
```

- name: `string`
  - `^[%w_%-%.:]+$`, up to 64 characters.
- exportName: `string`

**Returns**

- ok: `boolean`
- reason?: `'invalid_name'`, `'invalid_export'`

```lua
exports('getFines', function(source, page)
  return { total = 3 }
end)

exports.opx_core:RegisterCallback('myres:getFines', 'getFines')
```

`source` is set by the server; validate every other argument.

## SpawnVehicle

```lua
exports.opx_core:SpawnVehicle(record, coords, heading, options)
```

- record: `string` (`'Vehicle.*'` record)
- coords: `vector3` or `{ x, y, z, heading? }`
- heading?: `number` (degrees)
- options?: `table`
  - props?: `table` (applied with `Open77.vehicles.setProperties`)
  - plate?: `string` (A-Z 0-9 space -, 1 to 10, unique)
  - bucket?: `number` (default: the warped player's)
  - persistent?: `boolean` (never removed automatically)
  - owner?: `string` (citizenId given the key exception)
  - warp?: `number` (player seated as the driver)
  - locked?: `boolean` (locked for everyone except the owner)

**Returns**

- vehicleId: `number` or `false`
- reason?: `'not_ready'`, `'invalid_record'`, `'unknown_record'`, `'invalid_coords'`, `'invalid_plate'`, `'plate_owned'`, `'plate_in_use'`, `'invalid_bucket'`, or a platform reason

```lua
local id = exports.opx_core:SpawnVehicle('Vehicle.v_sport1_quadra_turbo_r_player', coords, 90.0, { warp = source })
```
