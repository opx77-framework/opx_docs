Keyboard menus and confirms for every OPX resource. The player keeps walking and looking around while a menu is open, and one menu is on screen at a time across all resources. Forms are drawn by [opx_dialog](/docs/opx_dialog).

## Installation

### Dependencies [step]

- [opx_dialog](/docs/opx_dialog)

### Download [step]

```bash
git clone https://github.com/opx77-framework/opx_menu.git
```

### Start order [step]

```jsonc
"opx_dialog",
"opx_menu"
```

Load it before every resource that uses it.

### Config [step]

Everything is in `config.lua`.

```lua
Config.locale = 'auto'      -- 'auto' follows the game language, or 'en' / 'fr'
Config.position = 'right'   -- default side: 'left' or 'right'
Config.keys = { up = 'UP', down = 'DOWN', left = 'LEFT', right = 'RIGHT', select = 'ENTER', back = 'BACKSPACE' }
Config.theme.accent = '#ff3b47' -- selection colour, #rrggbb
Config.sounds.enabled = true
Config.tilt.enabled = true  -- the menu leans toward the screen centre
Config.versionCheck = true
```

## Usage

- Up / Down: move through the rows (hold to repeat).
- Left / Right: change a list, slider, colour or checkbox.
- Enter: select. Backspace: back to the parent menu, or close.
- Escape: closes every menu.
- Keys are rebindable in Pause, Settings, Key bindings (`opx_menu`).
